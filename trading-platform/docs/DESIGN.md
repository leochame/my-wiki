# Northstar 界面设计

本轮（2026-11-18）参考以下产品的公开页面，提取布局与交互原则，使用自有组件实现：

- [Manus](https://manus.im/)：中性底色、留白、明确的主操作，减少装饰对任务的干扰。
- [Linear](https://linear.app/features)：紧凑的工作区导航、独立任务视图和键盘入口。
- [Vercel Geist](https://vercel.com/geist/introduction)：清晰的边框、组件状态、主题变量和文字层级。

## 页面结构

- 总览：账户摘要、行情接入提醒、行情与委托工作区、自选及最近订单。
- 市场与交易：专注行情和订单审阅。
- 我的自选：由用户主动维护，保存到既有 SQLite 接口。
- 资产与持仓：未接入账户查询时保持空状态。
- 订单记录：真实记录列表，支持方向筛选、证券或编号搜索、CSV 导出。
- 连接设置：展示实际配置状态和官方接入文档，技术变量收纳在可展开说明中。

## 视觉与交互

默认浅色：暖白画布、独立的浅灰侧栏、白色内容卡片、低饱和绿色强调。深色使用同一组语义变量，可切换并保存偏好。

Geist 和 Newsreader 通过本地打包的字体文件加载；不依赖运行时 Google Fonts 请求。金额使用等宽数字，买卖方向和错误状态除颜色外也有文字说明。

图标和空状态插图均为代码绘制。插图不包含虚构行情、持仓或成交数据；所有价格与图表都必须来自行情接口。

侧栏支持桌面收起和手机抽屉。`⌘/Ctrl K` 唤起搜索跳转，原生对话框管理焦点，支持 Escape，手机抽屉限制背景交互；尊重减少动态效果偏好。

## 实现入口

- `web/src/App.tsx`：工作区、路由状态、主题、弹窗。
- `web/src/components/WorkspacePanels.tsx`：行情、订单、自选、连接组件。
- `web/src/hooks/useWorkspace.ts`：真实 API 状态与委托流程。
- `web/src/components/Modal.tsx`：原生对话框及焦点恢复。
- `web/src/styles.css`：语义色彩、排版和响应式规则。

本轮不改变 Rust API 或数据库结构。继续保留预览失效、实盘确认和同一预览去重的既有规则。所有浏览器写入测试均使用独立的测试数据库。

## 本轮验证

- TypeScript 严格类型检查及生产构建通过。
- 320、390、768、1024、1440、1920 六种屏宽无横向溢出。
- 浅色、深色与添加自选弹窗的自动 WCAG A/AA 检查未发现违规项；此结果不等于完整人工可访问性认证。
- 浏览器实测主题保存、侧栏、命令搜索、添加/移除自选、订单预览/编辑/确认、持久记录、筛选与 CSV 导出。
- 预览失败时无确认入口，未授权行情保持空状态。
- 图表使用隔离浏览器数据验证币种、日期轴及悬停提示，不写入用户库。
