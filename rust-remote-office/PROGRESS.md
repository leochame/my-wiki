## 当前设计

- 邀请前缀 `rro1:`，传输 ALPN 为 `rust-remote-office/1`。数据结构固定，不包含版本协商字段。
- 采集线程负责截图、编码和切屏；输入线程独立处理键鼠、剪贴板及按键释放。输入事件携带接收时的屏幕坐标信息。
- 单帧在途许可覆盖采集、编码、发送和客户端确认。客户端解码重建后确认，完成时间用于调整采集节奏。
- 控制、画面、文件使用各自的 QUIC 流，控制优先，文件传输优先级较低。
- 文件按块传输并校验 BLAKE3，使用接收目录中的临时文件完成后提交，不覆盖同名文件。
- 分享期间的临时授权支持同身份重连；长期授权写入用户配置目录。固定身份与固定端口支持程序重启后的已授权连接。
- 已授权的同一设备重新连接时可以替换仍在收尾的旧连接；其他设备不能抢占活动会话。
- 非网络失败如拒绝连接、撤销和明确停止分享会结束自动重试。
- 系统调用与配置错误直接报告；本次没有加入旧版本迁移或兼容适配。

## 验证

当前使用 Linux、Rust 1.100.0。

核心测试 **31 项**：10 项单元测试与 21 项真实本机加密连接集成测试。测试桌面为模拟后端，文件传输使用实际临时文件。

```sh
cargo test --locked --no-default-features
cargo clippy --locked --all-targets -- -D warnings
cargo build --locked
cargo fmt --all -- --check
```

网络用例最多同时运行两组，每组仍包含并发的真实端点。没有把本机连接测试当成公网穿透验证，也没有把 Linux 编译结果当成 Mac/Windows 构建或 GUI 实测结果。

## 实机验收

1. Mac 控制 Windows，验证系统授权、屏幕、键鼠、中文、剪贴板及文件收发。
2. Windows 控制 Mac，验证 Retina 坐标、辅助功能权限、多屏与快捷键。
3. 配对受信设备，关闭图形界面运行 `--host`，验证已登录桌面的无人值守连接。
4. 验证断网恢复、程序重启、停止分享和授权撤销。
5. 验证跨网直连、中继及自定义中继，记录 RTT、实际刷新频率、画面流量和文件进度。

V1 当前覆盖已登录桌面。系统登录/提权桌面、音频、硬件视频编码、文件断点续传及 Linux 被控端不计入已实现项。
