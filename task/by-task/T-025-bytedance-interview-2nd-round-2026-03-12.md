## 项目深挖题库（面试官怎么追问，你怎么提前准备）
- **架构**：服务边界怎么划？为什么要拆/不拆？核心链路是什么？依赖哪些中间件？
- **数据**：核心表结构/索引怎么设计？读写比例？一致性要求？如何迁移/回填？
- **并发**：峰值 QPS？P99 延迟？线程/协程模型？怎么防止锁竞争/资源耗尽？
- **缓存**：哪些 key？TTL？一致性策略（旁路/写穿/延迟双删/订阅 binlog）？怎么防穿透/击穿/雪崩？
- **消息队列**：为什么用 MQ？幂等怎么做？重复/乱序/延迟如何处理？如何保证“至少一次”下的不重复生效？
- **一致性**：事务边界？分布式事务怎么处理（本地消息表/Outbox、Saga、TCC）？最终一致如何对账？
- **可观测性**：有哪些指标（RED/USE）？Trace/日志怎么关联？告警阈值如何定？
- **稳定性**：限流（令牌桶/漏桶）、熔断、降级策略？如何做压测和容量评估？
- **安全**：鉴权（JWT/Session）、接口签名、防重放、权限模型、敏感信息处理？

### MySQL 高频点（会被追问的细节）
- [ ] 索引：B+Tree、最左前缀、覆盖索引、回表、索引下推、联合索引顺序怎么定
- [ ] 事务：隔离级别、MVCC、幻读、间隙锁/临键锁（InnoDB）
- [ ] 慢查询：explain 怎么看、常见坑（函数/隐式转换/like 前缀%/order by filesort）
- [ ] 分库分表：分片键选择、全局 ID、跨分片查询、扩容迁移思路

### Redis 高频点
- [ ] 常用结构：string/hash/zset/list；各自适用场景
- [ ] 缓存一致性：旁路缓存写策略、延迟双删、订阅/消息驱动更新
- [ ] 雪崩/击穿/穿透：预热、随机 TTL、互斥锁、布隆过滤器
- [ ] 热点 key：拆分、二级缓存、本地缓存、限流

### MQ 高频点（Kafka/RocketMQ）
- [ ] 语义：至少一次/至多一次/恰好一次（业务侧通常做幂等）
- [ ] 幂等：唯一键/去重表/状态机；重复消息如何无害
- [ ] 顺序：同 key 分区；乱序如何容忍或改造
- [ ] 堆积：如何定位（消费延迟、lag）、扩容与降级策略

### 网络/HTTP 高频点
- [ ] TCP 三次握手/四次挥手、TIME_WAIT、半连接队列
- [ ] HTTP1.1 vs HTTP2（多路复用/头压缩）、TLS 基本流程
- [ ] 反向代理/网关：超时、重试、连接池、幂等性风险

## 代码题（手撕）清单：你至少要熟到“边讲边写”
- **复杂度意识**：先说 $O(n)$ / $O(n \log n)$，再写代码
- **边界条件**：空数组、单元素、重复元素、溢出、负数、极端输入
- **常见题型**：
  - 双指针/滑窗：最长不重复子串、最小覆盖子串、和为 K
  - 二分：边界收敛、lower_bound/upper_bound
  - BFS/DFS：最短路径、连通块、拓扑排序
  - 堆/TopK：海量数据/流式
  - 哈希/前缀和：子数组和、去重
  - 并查集：连通性
- **表达方式**：写之前口头说清楚状态定义/不变量/循环结束条件

## 系统设计答题骨架（强烈建议照这个展开）
1. **澄清需求**：核心功能、读写比、QPS/峰值、延迟目标、数据量、是否强一致、容灾等级
2. **API & 数据模型**：接口、关键字段、索引/唯一约束
3. **核心链路**：同步/异步划分、热点路径优化
4. **存储与缓存**：分层（本地/Redis/DB）、一致性策略、失效策略
5. **扩展性**：分片、无状态服务、水平扩展、隔离（租户/业务）
6. **可靠性**：超时/重试/幂等、限流熔断降级、消息补偿、对账
7. **可观测性**：指标、日志、trace、告警与 SLO
8. **安全**：鉴权、权限、审计、数据脱敏
9. **压测与容量**：如何评估容量、如何做回归与灰度
