## Non-Deadline Todo List

This file is for **tasks without a specific deadline** that are more concrete than vague ideas.  
Use it as a structured todo list for things you intend to do, but have not yet scheduled with a due date.

Guidelines:
- **When a task gets a real due date**, move it into `Active Tasks` in `TASKS.md`.
- Review this file regularly (e.g. weekly) and promote important items into `Active Tasks`.

---

### Todo Items (No Fixed Deadline)

Columns:
- **ID** — Short identifier (e.g. `NT-001`)
- **Task** — Clear and concrete description
- **Category** — e.g. Work, Study, Writing, Personal
- **Status** — Todo / In Progress / Waiting / Done
- **Priority** — High / Medium / Low
- **Notes** — Extra context if needed
