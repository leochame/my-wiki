# Andrej Karpathy 关注博客分类说明

这份清单整理了 Andrej Karpathy 公开推荐的 **91 个独立技术与深度思考博客**（源自其分享的 Hacker News 2025 热门博客 OPML 列表）。

在 MyWiki Studio 的「资讯」中心中，**不再单独设立 `Karpathy 92` 分组**，而是按内容主题拆解并归入以下 **5 个技术与思考类别**（每个订阅源下方均附带中文说明，保留 `Karpathy 关注` 标注以便识别）：

| 类别 | 数量 | 核心主题 |
| --- | ---: | --- |
| **AI 与前沿研究** | 10（+官方/研究者共 17） | LLM 训练实验、AI 工程评测、深度访谈、AI 安全与商业周期批判 |
| **系统与底层工程** | 23 | 编译器、操作系统内核、Rust/C++/Zig、数据库、Linux/BSD 与基础设施运维 |
| **软件工程与开发生态** | 19（+HN 共 20） | 前端/Web 架构、形式化验证、工程文化、开源包生态、独立产品开发 |
| **硬件、安全与极客逆向** | 20 | 网络安全调查、漏洞挖掘、芯片显微镜逆向、嵌入式硬件与计算机考古 |
| **数学、科学与深度随笔** | 19 | 应用数学、工业第一性原理、实验科学、创业战略、科技与社会评论 |
