## 核心流程

1. Client 提交文生视频请求。
2. LB / API Gateway 做路由、鉴权，并调用 Rate Limiter 检查 quota。
3. Backend Server 创建任务，写 DB，并把任务放入 Job Queue。
4. GPU Worker 从队列取任务，生成视频并写入 Object Storage。
5. Object Storage 通过 CDN 分发结果，Client 从 CDN 获取视频。



### 任务状态机

常见状态：

```text
PENDING -> QUEUED -> RUNNING -> MODERATING -> SUCCEEDED
                         |             |
                         v             v
                      FAILED       REJECTED
                         |
                         v
                      RETRYING
```

每次状态变化都写 DB，并记录错误码、重试次数、worker id、模型版本和耗时，方便排障与计费。


### 存储策略

DB 只存元数据，不存视频二进制。视频、缩略图、中间帧都进 Object Storage。对外分发使用 CDN signed URL，避免后端服务成为大文件下载瓶颈。
