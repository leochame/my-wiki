# Douyin Script Index

This folder is for Douyin short-video scripts.

## Suggested Structure

- one file per video idea
- filenames in `YYYY-MM-DD-topic.md` format for easy sorting
- keep each script short, punchy, and spoken-language friendly

## Recommended Script Sections

- hook
- core point
- examples or proof
- ending or call to action

## Scripts

- `template.md` — reusable short-video script template
- `2026-04-20-college-expansion-ai.md` — 大学扩招与 AI 话题脚本
