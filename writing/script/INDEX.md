# Script Index

This area is for scripts intended for spoken or recorded output.

## Main Branches

- `douyin/` for short-form video scripts prepared for Douyin

## Placement Rules

- If it is a script meant to be read on camera or recorded as audio, put it here.
- If it is specifically for short-video creation on Douyin, put it in `douyin/`.
- If it is only a rough topic seed and not yet a real script, keep it in `writing/idea-garden/`.
