# Writing Index

This area is for original writing that is meant to become publishable or at least coherent long-form output.

## Main Branches

- `technical/` for programming and engineering articles
- `personal-reflections/` for essays outside pure software topics
- `idea-garden/` for raw writing ideas, outlines, and half-formed article seeds

## Placement Rules

- If the piece is meant to become an article, it belongs in `writing/`.
- If it is still a vague thought or seed, put it in `idea-garden/`.
- If it is mainly for interview preparation rather than publishing, consider `job-search/` instead.

See `writing/technical/INDEX.md` for the technical article taxonomy.
