

# 网络

1. 操作系统内核参数调优

	- **开启端口重用 (`net.ipv4.tcp_tw_reuse`)** 这是**最推荐**的方法。它允许将处于 `TIME_WAIT` 状态的插口重新用于新的 TCP 连接。


	- **扩大本地端口范围 (`net.ipv4.ip_local_port_range`)** 如果并发量极大，可以增加可用的临时端口数量

	- **调整 MSL 时间 (`net.ipv4.tcp_fin_timeout`)** 虽然不能直接改变 2MSL 的硬性时间，但减小此值可以加快从 `FIN_WAIT_2`到 `TIME_WAIT` 的转换过程，间接缓解压力。

2. 网络架构调整

	- 通过 LB 分发流量，可以将压力分散到多台后端服务器上，增加整体可用的端口基数。
