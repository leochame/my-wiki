# 三个月价格模型：复现与边界

对应报告：`notes/理财/每日笔记/标普纳指可口可乐谷歌三个月预测-2026-11-06.md`。

## 运行

Python 3.10+，numpy、pandas、matplotlib；下载另需 requests。本次环境使用 numpy 1.26.4、pandas 2.3.3、matplotlib 3.10.9。

```bash
python download.py
python model.py
```

路径以脚本所在目录为基准。`download.py` 保留已冻结原始JSON；`model.py` 只读本地CSV、重新生成结果和图，不联网或访问交易账户。`manifest.json` 记录下载时间、参数、最后观察值和原始文件SHA-256。重复下载脚本会更新时间字段，但不代表已有原始文件重下。

## 数据

- Yahoo日频普通close，供应商已做拆股调整；模型刻意不用含分红adjclose，因为目标是股价、不是总回报。两个字段均保留以便审计。
- 股票指数自2000年下载，GOOGL自2004年上市起；联合样本取共同交易日，没有填补股票价格。模型主资产为GSPC、NDX、KO、GOOGL，IXIC仅作口径和回测参照。
- 日线时间戳通常指会话开始，报告“11-05收盘”依据交易日和日线字段，不把原始timestamp伪称为收盘时刻。
- 观察截止2026-11-05，美国11-06的非农尚未公布。未来窗口2026-11-06至2027-02-05，用星期一至五减11-26、12-25、01-01、01-18四个休市日，共62交易日；半日交易计一天。
- VIX和TNX辅助观察。VIX仅用于市场波动底值，TNX不作为拟合收益因子；VIX多出的非股票会话没有混入股票交易日，按日期匹配。

## 模型

- 简单市场beta用尾部252日样本协方差／标普方差。残差与自身实现波动都取21／63／252日样本标准差最大值。
- 市场sigma至少为VIX/100/sqrt(252)，其他资产sigma至少为sqrt(beta²×市场sigma²+残差sigma²)，也至少为自身实现波动。
- 将30日VIX用于62日预测是**状态假设**，不是真实三个月期权面；波动保持不变，未做均值回复或随机波动。这会扩大区间，回测已显示偏保守。
- 每日漂移等于尾部252日均值的25%，不拟合新闻分数，不搜索最佳参数。基准点为exp(H×mu)-1，与模拟中位数可能因经验分布不对称和序列相关而不同。
- 最多尾部1260日去均值、标准化的收益配对做5日循环区块重采样，20,000条路径，种子20261106。循环连接会引入人工区块边界；不能保证保留长周期依赖或复制未来尾部。
- 输出中的P10/P90为条件模拟分位数，不是经过概率校准的预测保证；逐日分位数带不是整条路径的同时包络。

## 回测

从最近可以完整观察62日后结果的起点往前，每62日一个起点，最少504日训练，共82个目标不重叠窗口，覆盖2008等阶段。每次只用当时及过去的特征和重采样池，2,000条模拟路径。全部历史数据为本次供应商快照，不是真正逐日存档的point-in-time数据库。

对照为零价格变化和始终预测上涨。方向胜率未超过上涨基准，KO和GOOGL点误差也未优于零变化，报告如实披露；不据此声称有交易alpha。时间窗口不重叠仍非完全独立。没有对新闻场景做回测，主观情景不配概率。

敏感性为1日和10日区块、1.5倍波动、只用实现波动。它们只用于判断输出对假设的依赖，不用于从结果选出更好参数。

## 输出

- `results/market_snapshot.csv`：统一收盘、历史涨跌、均线和回撤。
- `results/forecast.csv`：条件统计分位数、beta、波动、模拟频率。
- `results/news_scenarios.csv`：**主观**前瞻盈利预期变化与估值变化，经乘法产生价格情景。
- `results/backtest_windows.csv`、`backtest_summary.csv`：所有历史窗口和验证指标。
- `results/sensitivity.csv`：风险假设敏感性。
- `forecast.png`、`forecast.pdf`：可分享的四资产历史与未来条件风险带。
- `model_config.json`、`manifest.json`：参数和数据来源。

检查：无非正价格、重复日期，核对极端收益；检查未来交易日62天、最新价格时点、分位数排序和价格回报换算。新闻财务现金流用经营现金流减资本开支独立复核。检查实现不保证预测正确。
