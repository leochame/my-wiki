# 投资量化复核：复现说明

对应新研究笔记：`notes/理财/现有投资建议的数学复核-2026-10-29.md`。

## 运行

Python 3.10+；本次分析使用 numpy 1.26.4、pandas 2.3.3、matplotlib 3.10.9。下载脚本另需 requests、beautifulsoup4。

```bash
python download_data.py
python analyze.py
```

在已装这些依赖的环境运行。所有路径以脚本所在目录为基准。`analyze.py` 不联网，只使用冻结 CSV。下载脚本保留已有原始快照，不将重新访问网站后的修订值自动替换进去；`manifest.json` 记录本次快照哈希。`retrieved_at_utc` 是本次准备清单的时间，重新运行会更新这个字段，不代表全部原始文件都在该时刻重新下载。

## 数据与计算

- 股票数据：Yahoo chart 接口，1999-01-01 起、美国 2026-10-29 开盘前截止；采用日频 adjusted close，保存原始 JSON、收盘价和复权收盘价。用各交易所时区确定交易日。
- 长样本：SPY、QQQ、BRK-B 共同有效日；短样本：VOO、QQQM、BRK-B 共同有效日。股票日线没有填补缺失值；共同日期取交集。
- 人民币：美联储 H.10 历史网页，本次已公布的观察值截止 2026-10-23，按观察日期匹配。周末／节假日使用此前最近观察日的参考价；不延展到尚未公布的尾部观察日期。这是事后重建现金流，并非按每周发布日期重建实时信息集；H.10 也不是个人成交价。
- 月度窗口：仅用截至 2026-09 的完整月份。月末标签是日历月末，实际股票价格是该月最后一个共同交易日收盘。
- 组合：在起始收盘价建立目标权重，持仓漂移，6 月和 12 月最后共同交易日收盘后恢复目标。月频定投按金额新增目标权重，半年恢复全账户权重。均不计个人税、汇款费、交易费和换汇价差；基金内部费用已嵌入基金价格。
- 定投：每两个月期末 20,000 元，60 个月共 30 次；排除初始 5,000 港币。每个滚动窗口从零持仓开始，不是同一实盘账户反复截取余额。
- 定投年化资金加权收益：用等间隔月数反解年有效利率，非精确到自然日的 XIRR；结果文件已注明 `annual_money_weighted_return`。
- 区块重采样：对已经包含再平衡效果的组合月度对数收益和基准收益配对、循环取块。每次抽取至与原样本同长，计算两个几何年化之差；没有在新路径上重新执行再平衡，也未校正事后资产选择。用途是诊断历史差异的不确定性，不是预测未来的置信区间。
- 压力情景：股票美元市值统一跌 55%，USD/CNY 从 6.67 变为 6.00，人民币现金瞬时收益设为零。假设期间没有再平衡或新入金。此情景不是最大损失界限，也不假设股汇一定同时朝这一方向变化。

## 数据质量

备用 Yahoo CNY 序列在 2011-07-18／19 存在异常跳点；因此不用于任何结果。早期试读的 ECB CSV 也未用于结果。相关备用快照保留在 `raw/`，**不能用它们代替 `FED_USDCNY.csv`**。

检查了非正价格、重复交易日、缺失值、极端日变化。单资产净值对照、现金流独立求和、定投单位数独立复核及资金加权收益反解均在脚本中断言。历史窗口高度重叠，历史亏损窗口占比不能当作未来概率；BRK.B 的存续与选择存在事后偏差。

主要输出：`results/*.csv`、`investment_review.png`、`investment_review.pdf`。报告中的百分比与万元表为原始计算值四舍五入。
