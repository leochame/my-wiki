# 香港三夜行前与开户执行清单

核查日期：2026-11-04，香港／北京时间。

适用情况：人在北京，山东德州户籍，程序员，收入以工资为主；已有身份证和护照，没有北京居住证、港澳通行证、赴港签注及香港银行账户。预计住三夜，具体日期和交通未定，希望选内地休假而香港正常营业的日子。旅游优先，手机可办理的项目尽量顺路完成，线下预留半天处理必要手续。

本清单结合两篇指定 Linux.do 帖子及其可见回复、帖子中的出入境记录步骤图和汇总图，并核对官方规则。论坛审核时长、设备故障、推荐码与网点经历是个案；账户资格、费用和启用状态按银行确认。原笔记保留，相关内容见 [[香港银行开户与账户验收清单-2026-10-17]]、[[赴港开户补充-定位与漫游-2026-11-04]]。

## 一、这几天先办什么

- [ ] 通过“移民局12367”小程序或 App 的“中国公民服务 → 现场办证预约”，选择北京，申请首次港澳通行证，并同时申请赴香港团队旅游签注（L）。全国通办路径不要求北京居住证；首次申请须本人到场。[O1][O2]
- [ ] 预约时确认材料：身份证原件，制证照片、申请表及指纹按大厅流程办理。北京提供现场免费采集制证照片；一般成年人申请不需为全国通办另准备社保证明或居住证。登记备案人员等特殊身份另按规定。[O1][O2]
- [ ] 通行证60元，一次签注15元，合计通常75元；北京公布一般7个工作日，实际取证以受理回执为准，受理当天、周末、法定节假日及邮寄另留时间。首次申请不是去签注机即可立等取证。[O2]
- [ ] 日期未定时核对签注有效期，可询问一年一次选项；确认取证时间后再确定交通与三夜住宿。
- [ ] 筛选日期时分别查香港公众假期及目标银行营业日，争取有两个完整银行工作日。内地放假不等于香港工作，香港普通周末也不等于完整银行工作日。
- [ ] 本周整理电子材料和一份纸质备份，检查官方 App、手机 NFC、短信、邮箱及备用机。行前再次确认银行当日条件。
- [ ] 通行证到手且赴港日期确定后，如决定办理工银亚洲分行渠道，可先在内地App提交资料并预约，等待预审批；南洋商业银行也可先通过官方预约平台预填资料、联系分行确认后续核验。接听需要的回访并留意短信、邮箱，记录本人预约；不要把论坛作者的预约短信当作自己的预约。[O22][O23]
- [ ] 如选择建行亚洲分行开户，先通过官方预约页选分行、填表；官网说明银行于提交后3个工作天内电话联系确认预约及到店日期、时间。此项是预约流程，不等同已经完成账户预审批。若选访港e账户App路径，则抵港后再提交。[O13][O27]

### 建行与工银：是否必须先线上申请、再预约线下

按渠道判断，不把“线上预约”“账户预审批”“正式开户”混为一步。

| 渠道 | 行前是否要线上办理 | 顺序 |
| --- | --- | --- |
| 工银亚洲App「全新客户网点开户」 | 走此渠道须先提交App申请，预约在申请过程中选择 | 内地App填资料并选分行/日期 → 等预审批通知 → 按约赴港核身及申请启用；不是必须等电话通过后才另约分行。[O22] |
| 工银亚洲VTM | 官方说明新客户可无需提前预约直接使用VTM服务 | 带材料赴港 → VTM视频柜员审核 → 成功后领提款卡。若已提交其他渠道申请，转换渠道前先向银行确认。[O14] |
| 建行亚洲分行预约 | 为安排确定到店时间，行前填写官方网上预约表 | 选分行填表 → 银行于3个工作天内电话联系确认日期/时间 → 按约携材料到店办理。预约确认不等于开户已批准。[O27] |
| 建行亚洲访港e账户 | 不用行前先获线上预审批，申请时须在香港 | 行前下载App准备材料 → 抵港到适合地点用App提交 → 等最终核实 → 有补件、特定功能需求时再按指引到分行。[O13] |

就本次三夜行程：如想在香港分行把开户或必要功能一次处理，可行前安排工银App预审、建亚分行预约；如更重视减少跑银行，可保留工银VTM及建亚在港App申请选项，具体选定一种主渠道。建亚FAQ另列有带证件到分行申请的选择，未查到所有线下客户都必须先在内地通过账户预审的统一规定；现场是否有名额须向分行确认。[O13][O14][O22][O27]

### 工银亚洲、南商：可在内地先预填／预审

| 银行 | 行前步骤 | 赴港带什么、办什么 |
| --- | --- | --- |
| 工银亚洲 | 官方App → 新客开户 → 中国居民身份证全新客户网点开户 → 按真实情况填资料、验证手机和邮箱 → 预约分行及日期 → 等预审批短信和电邮 | 身份证原件、通行证原件、申请时使用且已开漫游的内地手机号；按需提供近三个月地址证明原件。按本人预约到店，完成身份核实、正式审核及账户启用。[O22] |
| 南商香港 | 从官网“网上预约开户（个人）”进入，或通过官网指引的南商e+／官方微信公众号预填及预约，查看补件与通知 | 按本人申请要求携身份证、旅行证件及相应住址、职业、收入和用途材料到预约分行。官方材料支持提前填资料、到港核验；本次未找到所有客户都必须先接一次电话回访的统一规定。[O23] |

工银该App渠道官网要求：申请人年满18岁、身份证及辅助旅行证件各至少还有100天有效期，赴港办理当天签注有效；银行接受的辅助旅行证件包括通行证或中国护照。你这次是专程赴港旅游，仍按通行证＋签注安排出行，银行接受护照作为材料不等于护照本身提供赴港旅游资格。[O22]

把“预审批通过”理解为可以按约进入后续核验，不能据此认定账户已最终开立、能收付款或必获信用卡。电话核实属于可能环节，按本人官方通知完成；工银公开流程明确的是审核后短信／电邮通知，并未要求所有渠道、所有客户一律电话先审。[O22]

### 建行亚洲：提款优势与信用卡条件另确认

建行亚洲现有访港e账户手机申请渠道；分行网上预约路径则由银行电话联系确认到店时间，不能将电话预约确认一律理解为账户预审批。开户后的必要到店事项包括非香港居民第三方转账申请、部分签名服务等。[O13][O27]

| 提款场景 | 当前官方产品页说明 |
| --- | --- |
| 内地中国建设银行ATM提取人民币 | 对银联双币提款卡提供提款／查询手续费豁免；核对人民币账户余额及所连系账户。[O24] |
| 香港本行及银通ATM | 本行豁免提款／查询手续费。[O24] |
| 内地其他银行ATM、其他海外ATM | 不作全渠道免费承诺；可能涉及发卡行手续费、当地ATM收费及兑换成本，按具体网络、币种和收费表确认。[O24] |

这些指储蓄账户提款卡，不是信用卡现金透支。手机钱包支持情况也按具体卡种核对；银行账户的转账、储蓄及现金提款用途可分别评估。

“存10万港币可办信用卡”保留为论坛经验线索，本次未查到存满该金额即可获批的统一现行官方条款。应先确认本人身份是否受理、目标卡种、收入／资产材料及审批条件；普通存款、定期存款和质押存款也可能有不同要求。信用卡产品及奖励条款不能当作存款后必获批的承诺。[O25]

如确有香港信用卡需求，赴港前向官方分行确认：无香港身份证是否受理、可申请哪张卡、需要普通存款证明还是质押／冻结存款、金额与维持期限、信用额度及年费。确认条件与资金安排合适后再决定；不把先存10万作为本次行程的默认任务。

## 四、网络、短信和定位

### 行前分别确认三层漫游

| 层次 | 确认事项 |
| --- | --- |
| 运营商端 | 国际/港澳台漫游功能、香港短信/通话及所需数据业务可用；确认没有数据漫游禁用设置 |
| 流量包 | 适用地区包含香港，生效时间、有效期、额度及超额资费清楚；购买套餐本身不等于已开通所有漫游服务 |
| 手机端 | 使用内地卡漫游上网时，该卡移动数据和数据漫游开关已打开，并正确选为数据卡 |

这些是分别检查的设置；中国移动官方指南也区分运营商漫游功能与手机端开关。短信/通话漫游与数据使用分开确认。[O15]

双卡时，若由另一张卡提供流量，可关闭不承担上网任务的内地卡数据漫游及自动数据切换，保留银行登记号的短信/通话漫游。香港本地号码不是上述所有银行的统一前提。

### 抵港后先安顿，再申请

1. 入境后保留入境凭证，先前往酒店或城区休息点；边境和移动车厢不作为计划中的开户地点。
2. 罗湖口岸香港侧为罗湖站，福田口岸香港侧为落马洲站，两者往市区下一站均为上水；深圳高铁福田站是另一回事。走这条路线时，上水可作候选休息点；直飞香港或高铁到西九龙时不用绕去上水。[本地补充]
3. 找可信网络、光线均匀且适合自拍的位置。允许App使用定位、精确位置、相机及NFC；暂停会改变网络出口的VPN/代理，以真实所在位置提交。商场或餐厅品牌本身不决定能否开户。
4. ZA官方要求香港主要城区。各行地理核验不同，上水不保证所有App都接受。WeLab官方建议：漫游网络定位报错时改连安全Wi-Fi再试。[O6][O12]
5. 先确认上网与短信/来电正常，再开始填资料。收不到验证码时按顺序检查漫游开通状态、信号、短信拦截及运营商限制，必要时由运营商指导手动选网；有备用机可辅助排障。不能由一次故障推断某品牌手机一定不可用。

### 出入境记录怎样获取

- [ ] 出发前注册并熟悉“移民局12367”，抵港后进入“中国公民服务 → 出入境记录查询”，查询并下载包含本次行程的PDF；界面名称以当前版本为准。[O2]
- [ ] 文件未更新时稍后再查，帖子所述十几分钟只是个案，不保证统一更新时间。
- [ ] 保存原始PDF到本机安全目录，银行要求有效期或当日签发时重新生成。中银是7日内，WeLab要求开户当日签发。[O3][O12]
- [ ] 若取得的是加密压缩包，先用官方提供方式解压取得PDF；上传规格按银行说明，保留原始文件，不改姓名、日期或记录。
- [ ] 内地记录通常体现内地出境，不是香港入境处出具的记录；香港入境小票也不必然替代银行指定的国家移民管理局文件。

## 五、现场操作与离港前必须检查的事

| 情况 | 做法 |
| --- | --- |
| NFC反复失败 | 查看机型感应位置，取下可能干扰的手机壳/卡套，证件贴近感应区并保持稳定；确认App仍在读证步骤 |
| 证件拍摄/OCR失败 | 擦镜头，避反光和阴影，完整露出证件边角；核对识别出的中文名、拼音和证件号，错误未纠正前不提交 |
| 已提交待审核 | 保存申请编号和通知，按官方渠道跟进。去分行先说明已有申请，由银行决定补件、转渠道或重申，避免重复申请 |
| 明确拒绝 | 依指引联系官方客服或预约分行，不反复改变真实职业、地址和用途去试通过 |
| 最终开户成功 | 立即继续网银登记、设置登录凭证及安全令牌，重新登录核对；开户成功不等于卡片、投资和所有转账功能均已启用 |
| 更换了开户设备 | 查清安全令牌迁移和额外认证是否完成，恒生可在“设定及安全 → 设备及应用程序设置 → 认证身份”检查。[O5] |
| App提示须签名或到店 | 先询问是否仍在审核，确认真正需要到店的服务和材料；中银完整服务及建行亚洲第三方转账存在相应到店要求。[O3][O13] |

### 有真实需求时在港申请投资服务

ZA官方确认：访港客户首次申请投资账户必须人在香港，已有储蓄账户也可以以后再来香港申请，并非必须与储蓄在同一分钟开通。[O16]

但其官网另要求访港投资客户就境外合法资金来源等作出声明。你目前仅确认收入以工资为主，尚未核实境外资金来源，因此只有本人确实满足资格、能真实作出声明且有使用需求时才申请，不为奖励默认勾选。股票服务还可能要求三个月内住址证明、W-8BEN等。[O17]

其他银行的投资服务按自己的客户资格、材料和地域条件判断；不能把ZA要求套到大象、恒生或中银。开银行自带投资账户也不是向外部券商转账的通用前提。

### 离港前检查

- [ ] 逐家记录：最终获批／待审核／待补件／拒绝，以及申请编号和下一步。
- [ ] 网银可登录，安全令牌及必要额外身份认证完成；核对英文姓名、手机号、邮箱及邮寄地址。
- [ ] 确认是否须到店留签名、认证或开通第三方转账等服务，把必要手续放在预留半天内。
- [ ] 核对本地转账、海外电汇、消费和提款功能及限额；默认限额为零、银行临时上限与审核未完成是不同状态。
- [ ] 卡片按需申请，问清提款卡/借记卡种类、寄送费用、投递方式、PIN及激活步骤；不以三夜内全部拿到实体卡为前提。
- [ ] 如需要FPS手机号或邮箱收款，选定常用默认收款银行并核对，不在每家注册后就认为每家都是默认收款行。
- [ ] 有正常付款需求且账户允许使用时完成一次小额支付并核对结果；不存在为“养卡”专门刷流水的任务。
- [ ] 记录管理费、余额计算口径、临时限制到期规则和回内地后的补件渠道。

## 六、三夜怎样安排，旅游优先

| 阶段 | 办事安排 | 留给玩的时间 |
| --- | --- | --- |
| 行前 | 办证、材料、App及漫游一次准备；如选工银或南商，先预填／预审并确认本人预约及补件要求 | 不把关键材料留到香港现找 |
| 抵港当天 | 先吃饭/入住，休息时生成记录并提交两三家主要账户申请；ZA可先用来检查设备和短信，也可按预约时间先办其他行 | 其余照常逛街、看夜景 |
| 第一个完整银行工作日 | 预留一个上午处理主要银行的必要补件或预约；有现成路线可考虑市区VTM | 下午与晚上正常玩 |
| 另一个完整日 | 早餐/咖啡/酒店休息时提交平安、大象、蚂蚁等扩展申请；汇立只在有效推荐码已确认时尝试 | 主体安排景点、徒步或购物；coffee chat有约上就顺路一小时 |
| 离港日 | 对照上一节核对状态、必要到店待办和邮寄信息 | 预留正常交通余量 |
| 回北京后 | 跟进正式补件和来电，收卡激活、核对费用，再按实际用途使用 | 无需在港等到所有人工审核完成 |

## 七、两帖中需要更新或按条件理解的细节

| 主题 | 本清单采用的结论 |
| --- | --- |
| 证件有效期、首存与现金 | 不存在两帖所能证明的全银行统一半年有效期或固定现金激活金额。逐行看证件条件，现金按旅行实际需要准备。[O3][O6][O7] |
| 开户渠道 | 汇丰除App外，现有数码银行站支持通行证新客户，成功开户并符合条件时可即时领取ATM卡；分行路径也应先确认指定受理点。[O8] |
| 工银、南商与建亚的预审 | 工银有App预审批后赴港核验渠道；南商有预填预约渠道；建亚分行预约明确电话确认到店安排，另有在港e账户渠道。三家的预约、电话核实与账户批准不能视为同一种流程。[O13][O22][O23][O27] |
| 网点预约 | 两帖对中银预约提前量的经验不同，不能据此承诺某天统一放号。确定日期后查看官方实时预约；线下不保证即场拿卡。 |
| 名字、天气、语言与审核 | 未找到两字姓名必然被拒、下雨免排队或混用英语更易获批的通用官方依据；核对姓名拼音，以能清楚表达真实情况的语言交流。 |
| 投资服务 | ZA有在港申请及境外合法资金声明条件；不是为了完整权限或返现就必须申请所有银行投资服务。[O16][O17] |
| 实体卡奖励 | 帖子里的组团、Lv2、邮费豁免和迎新活动须查当期官方条款。先看适用身份、有效期、实际到账、成本及后续收费，不直接采用帖子代码。 |
| 数字银行补件 | 已提交的申请能否离港后继续补件，由银行具体流程决定；被拒后重新申请可能重新要求在港，不能一概认为回内地都可重申。 |
| AlipayHK | 电子钱包，不是银行账户；注册与完整实名认证不同。官方对未完成证件扫描和自拍认证客户的余额转账、淘宝及跨境用途设有限制；蚂蚁银行连接是否可用看本人App。[O18] |
| Wise | 有相应资格并获发港币收款资料的账户，可按本人指示接收FPS；Wise不收FPS收款费，付款银行可能收费。帖子中的固定激活金额、所有人都可获卡及全链路免费不是统一保证。[O19] |
| 境外消费与服务订阅 | 发卡行、卡组织、商户受理及服务地区要求分别确认；持香港账户或中转到另一张卡不能证明任意服务均可订阅。 |
| 券商和资金 | 券商开户名单不能沿用年初帖子。内地个人普通购付汇不因进入港卡、Wise或其他中间账户就能用于尚未开放的境外证券投资。[O20] |
| CRS和税务 | 增加中间账户不构成免申报或免税结论；开户按真实税务居民身份填写，香港金融账户有自动交换资料制度。[O21] |
