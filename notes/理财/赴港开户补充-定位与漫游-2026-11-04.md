# 赴港开户补充：定位与漫游

核查日期：2026-11-04，香港／北京时间。

完整行前、银行选择及离港验收安排见 [[香港三夜行前与开户执行清单-2026-11-04]]，已结合用户补充的两篇 Linux.do 帖子核对。

补充 [[香港银行开户与账户验收清单-2026-10-17]]。用户偏好：旅游为主，抵港后到合适地点坐下来再申请，不在边境或移动中的车厢反复尝试。

## 一、到城区再办理

- [ ] 过关后先完成交通、入住或用餐安排，到符合目标银行地域条件、网络稳定且光线均匀的位置，再开始开户。
- [ ] 若走罗湖口岸，香港一侧为东铁线罗湖站；若走福田口岸，香港一侧为落马洲站。两站往市区方向下一站均为上水。这里的福田口岸不等于深圳高铁福田站。[S1]
- [ ] 可把上水附近商场、咖啡店或银行附近作为休息与检查网络的候选地点；若本就前往市区酒店，可到酒店后办理，不必特意在上水停留。
- [ ] 开启银行 App 所需定位权限；支持精确位置设置的设备同时检查该项。准备好相机及 NFC，自拍时避开反光、阴影和杂乱背景。
- [ ] 出现地域或定位错误时，核对所在位置、银行允许区域、定位权限及网络，必要时联系官方客服。

ZA Bank 官网明确要求访港开户者身处香港境内的主要城区，并提供建议区域示意图。[S2][S3] 不能把这一要求推广成所有银行统一的规则，也不能保证到上水后每家银行必定接受定位。城区安排是减少现场反复尝试的操作建议。

## 二、漫游逐层确认

使用内地 SIM 卡在香港通过漫游上网时，以下三项需要分别检查，购买流量包不能自动证明其他两项已完成。[S4]

| 层次 | 出发前／到港后检查 |
| --- | --- |
| 运营商服务 | 向本人运营商确认国际／港澳台漫游已开通，香港的数据业务、短信及通话服务可用，且没有数据漫游禁用设置 |
| 资费套餐 | 香港适用的境外流量包已订购，确认生效日期、有效期、流量额度及超额资费 |
| 手机设置 | 需要漫游上网的 SIM 已选为数据卡，移动数据及数据漫游开关已打开 |

- [ ] 内地开户手机号到港后可正常收验证码、接听银行核实电话；能够上网不等于该号码能收短信和接电话。
- [ ] 使用双卡时，区分数据卡与银行登记号码。若用香港卡或另一张卡上网，关闭不承担上网任务的内地卡的数据漫游及自动数据切换；保留所需的短信、通话漫游服务。
- [ ] 抵港后先确认网络与短信可用，再开始银行申请；若使用 Wi-Fi，选择可信网络，不要求必须使用某一品牌餐厅的 Wi-Fi。
