# 如何去参加展会：与创业者怎样进行有效的聊天（理论版）

​

我曾经参加过亚马逊、谷歌等公司举办的峰会。现在想起来，我浪费了很多次机会：当时太在意项目够不够新奇、分享了什么具体技术，却没有抓住更有价值的事——和创业者进行一次深入的交流。

​

## 杜绝愚蠢与傲慢

​

“这个不过是营销。”“这个没啥壁垒。”“这个有啥技术？”

我接触过世界上最大的群体——韭菜，也接触过另一种人——自认为懂的韭菜。

​

不理解对方的思维模式，不等于对方没有想明白。要是我们什么都能理解，那最应该准备的是在纳斯达克敲钟的姿势。

​

所以下次先看现场的海报、看 demo，尽量弄明白产品在做什么。对方回答时耐心听，聊完诚挚地道谢。

​

​

## 不要像低级 VC 一样问问题

​

千万不要一上来就问：“你们产品最大的壁垒是什么？”

​

我曾经以为，清楚地回答“壁垒是什么”，是成为成功创业者、做出成功产品的先决条件。但看到 OpenAI、Anthropic 这些 AI 新势力，以及 Claude Code、Manus、Codex、Cursor 等 Agent 产品带来的变化，我越来越怀疑这个问题能否解释早期产品的成败。旧时代互联网大厂拥有的人才、资金和技术优势，并没有让我看到有这些资源就能赢。

​

我当然总结不出这些公司或产品成功的秘诀。至少在展会现场，与其笼统追问“壁垒”，得不到有价值的回答。相比之下，更值得问的是：你们最初看到了什么机会，如何确认它不是错觉，又是怎样把产品真正交到客户手里的？

​

​

## 正确的问题是什么

​

我们应该询问的是，他们怎么看到这个机会的？怎么意识到这个市场的？客户的付费意愿怎么样？

​

对于 Agent 产品，我们可以着重问一下，客户为什么不用 Codex，Claude Code 等通用 Agent&#x20;
